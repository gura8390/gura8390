# gura8390

个人工具、网页游戏与 Paradox 模组静态检查器。
Personal utilities, browser games, and Paradox modding tools.

## 实用工具

| 项目 | 用途 | 入口 |
|---|---|---|
| [ClickRun Modern](https://github.com/gura8390/ClickRun.Modern) | Windows 鼠标连点器，支持热键与参数方案 | [下载](https://github.com/gura8390/ClickRun.Modern/releases/latest) |
| [PDF Keyword Analyzer](https://github.com/gura8390/PDFREADER) | PDF 关键词、人名、页码与上下文统计 | 源码运行 |
| [Copy on Web Freedom](https://github.com/gura8390/COPY-ON-WEB-FREEDOM) | 自动复制选中文本与解除常见复制限制 | [脚本安装](https://greasyfork.org/zh-CN/scripts/497808) |

## 模组开发工具

| 项目 | 范围 |
|---|---|
| [Tiger CK3](https://github.com/gura8390/Tiger-CK3) | 基于 amtep/tiger 的 CK3 1.20.1 规则适配与诊断修复 |
| [Tiger Stellar](https://github.com/gura8390/Tiger-Stellar) | Tiger 衍生解析器与独立群星 4.5.2 语义检查层 |

两个检查器都保留原作者署名、来源说明与检查边界；静态检查不等于游戏引擎验收。

## 网页游戏

| 项目 | 内容 |
|---|---|
| [KUBI · 超苦逼冒险者](https://github.com/gura8390/KUBI) | 数据驱动的文字生存冒险 · [在线入口](https://gura8390.github.io/KUBI/) |
